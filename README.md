# ML-Techniques-For-Used-Car-Data-From-Saudi-Arabia

# Description
This project challenges you to apply machine learning techniques to real-world used
car data from Saudi Arabia. Using a dataset containing information about 8,248 used
cars collected from syarah.com, you will gain practical experience in developing and
evaluating machine learning solutions while extracting meaningful insights from the
Saudi Arabian used car market.

# Requirements
- Code Language: Python
- python version: from 3.8.0 up to 3.12.0
- IDE: Google Colab / vscode / Jupiter notebook
- Dataset: https://www.kaggle.com/datasets/turkibintalib/saudi-arabia-used-cars-dataset
- libraries: Pandas / Numpy / scikit-learn / joblib, use the following: (pip install pandas numpy scikit-learn joblib)
